# Changelog / Cambios

## 1.1.0

🇬🇧
- **English and Spanish**: the whole extension (catalog, Music tab, messages, status bar, commands and settings) is now available in both languages. New **Idioma / Language** setting in the catalog: Automatic (follows VS Code), Español or English.
- **Update notifications**: Aura checks GitHub once a day and offers to download and install new versions with one click. New command **Aura: Check for updates** and `aura.checkForUpdates` setting.
- Aura only asks to restart VS Code after an update when the injected code actually changed.
- README available in English (main) and Spanish (`README.es.md`).

🇪🇸
- **Español e inglés**: toda la extensión (catálogo, pestaña Música, mensajes, barra de estado, comandos y ajustes) está en los dos idiomas. Nuevo ajuste **Idioma / Language** en el catálogo: Automático (sigue a VS Code), Español o English.
- **Avisos de actualización**: Aura revisa GitHub una vez al día y ofrece descargar e instalar las versiones nuevas con un clic. Nuevo comando **Aura: Buscar actualizaciones** y ajuste `aura.checkForUpdates`.
- Aura solo pide reiniciar VS Code tras una actualización cuando el código inyectado cambió de verdad.
- README en inglés (principal) y en español (`README.es.md`).

## 1.0.0 — First public release / Primera versión pública

- **Glass over the desktop / Cristal sobre el escritorio**: VS Code translucent over your desktop or Wallpaper Engine, with adjustable visibility from the status bar.
- **Background catalog / Catálogo de fondos**: animated gradients, album cover, custom image; glass panels compatible with the new VS Code 1.144 layout.
- **Music tab / Pestaña Música**: player with cover art, real frequency visualizer (audio capture + FFT), progress and controls; transparent or retro style.
- **Backgrounds that react to music / Fondos que reaccionan a la música** with the album colors.
- **Fonts / Fuentes**: coding and video game catalog (Minecraft, Mario, Mario Kart, Zelda, Pokémon, Undertale…), in the code or the interface.
- **One-click font installs / Instalación de fuentes con un clic** from Google Fonts, GitHub or dafont, no admin rights; detection of manual downloads (with confirmation).
- Experimental acrylic/mica transparency (Windows 11).
- Exact restoration of VS Code when disabling or uninstalling.
