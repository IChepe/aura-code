# Cambios

## 1.0.0 — Primera versión pública

- **Cristal sobre el escritorio**: VS Code translúcido sobre tu escritorio o Wallpaper Engine, con visibilidad ajustable desde la barra de estado.
- **Catálogo de fondos**: degradados animados, carátula de la música, imagen propia; paneles de cristal compatibles con el nuevo diseño de VS Code 1.144.
- **Pestaña Música**: reproductor con carátula, visualizador de frecuencias real (captura de audio + FFT), progreso y controles; estilo transparente o retro.
- **Fondos que reaccionan a la música** con los colores del álbum.
- **Fuentes**: catálogo para programar y de videojuegos (Minecraft, Mario, Mario Kart, Zelda, Pokémon, Undertale…), en el código o en la interfaz.
- **Instalación de fuentes con un clic** desde Google Fonts, GitHub o dafont, sin permisos de administrador; detección de descargas manuales (con confirmación).
- Transparencia acrílico/mica experimental (Windows 11).
- Restauración exacta de VS Code al desactivar o desinstalar.
